# Ioskeley Mono web fonts

- Source: https://github.com/ahatem/IoskeleyMono
- Release: `v2.1.0`
- Package: `IoskeleyMono-Web.zip`
- License: SIL Open Font License 1.1; see `OFL.txt` in this directory.

The renderer bundles only the Regular, Italic, Medium, and SemiBold WOFF2 faces used by the interface. Chinese text falls back to the platform CJK font stack.
