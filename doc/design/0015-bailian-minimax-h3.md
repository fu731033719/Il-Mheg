# 百炼 MiniMax H3 实现记录

验证日期：2026-09-27。

`bailian-minimax-h3` 显示为「MiniMax H3（百炼）」，使用现有北京 `dashscope` Provider、加密密钥和精确上游名称 `MiniMax/MiniMax-H3`。原有 MiniMax 官方直连模型保留。

模型目录声明文本、帧控制、参考图三个端点，默认 2K、5 秒，支持 768P/2K 和 4–15 秒。文本使用明确画幅，首帧/首尾帧使用 adaptive，参考图最多九张。未新增独立尾帧、视频或音频输入。

DashScope 视频适配器按端点选择媒体传输和参考图类型；H3 的参考图字段为 `image_url`。本地图片在实际生成时通过百炼上传策略传至私有临时 OSS，以 `oss://` 地址和资源解析请求头提交。上传校验图片格式、大小、私有 ACL 和阿里云 OSS HTTPS 域名，随机化文件名，保持输入顺序，且不给 OSS 附带百炼 API Key。轮询沿用 DashScope 任务接口，不重复上传。
