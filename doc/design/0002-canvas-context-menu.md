# 画布右键创建节点实现

## Renderer 画布

- `CanvasWorkspace` 不再渲染 `EmptyCanvas`，因此无节点项目保持为空白的可操作画布，顶部工具栏、缩放控制和小地图仍然可用。
- React Flow 的 `onPaneContextMenu` 负责拦截空白区域原生右键菜单。处理器使用 `screenToFlowPosition` 将屏幕坐标转换为画布坐标，同时将弹出层位置约束在当前工作区内。
- 画布菜单状态分别保存弹出层坐标与画布坐标。前者负责菜单显示，后者传入 Store 创建节点，使缩放和平移后的创建位置仍与用户右键位置一致。
- 打开右键菜单会关闭连接创建菜单并清除画布选择。画布点击、菜单外指针按下、`Esc` 和项目切换都会关闭右键菜单。

## 节点菜单

- `NodeCreationMenu` 提取了共享的 `NodeTypeMenu` 渲染层；连接创建菜单与画布右键菜单复用相同的图标、标签、主题样式和菜单项结构。
- 画布右键菜单固定提供提示词、图片生成、视频生成三种可执行节点。分组不在菜单中创建，继续由顶部工具栏对当前多选节点执行。
- 菜单声明 `role="menu"` 和对应可访问名称，并阻止菜单内部事件触发画布操作或浏览器原生右键菜单。

## Store

- `addNode` 新增可选的显式坐标参数；右键创建使用该坐标，顶部工具栏未传坐标时继续使用原有网格排布位置。
- 两种入口均复用既有 `commit`，因此继续支持撤销、重做与防抖持久化。

## 已验证事实

- Store 自动化测试验证显式坐标不会被默认网格位置覆盖。
- `pnpm verify` 全量通过：TypeScript 类型检查、45 项测试（43 通过、2 跳过）、Renderer/Desktop 生产构建和 Electron Runtime smoke test 均成功。
- 1280 × 720 浏览器预览确认空画布不显示引导卡片；右键菜单显示三类节点；选择提示词后菜单关闭，节点出现在右键对应位置。
