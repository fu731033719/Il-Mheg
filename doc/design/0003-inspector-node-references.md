# 属性面板节点引用导航实现

## 预览素材解析

- `lib/node-preview.ts` 集中提供 `nodePreviewAssetId`，画布节点和属性面板引用卡片复用同一套素材优先级。
- 图片节点优先读取首个输出素材，没有输出时回退到导入的 `sourceAssetId`；视频节点读取首个输出素材；提示词和分组不返回媒体素材。

## 属性面板

- `NodeInspector` 将当前节点的入边解析为来源节点、绑定语义和可用素材，孤立边不会生成引用项。
- 每条引用渲染为完整可点击的 `NodeReference` 按钮，显示 44×44 缩略图、绑定名称、来源节点名称和导航箭头。
- 图片素材使用裁切图片预览，视频素材使用静音且无控件的视频缩略预览；没有素材的节点按提示词、图片或视频类型显示 Lucide 占位图标。
- 引用按钮包含来源节点名称的 `aria-label` 与 `title`，并提供悬停和键盘焦点状态。
- 点击引用项调用 Store 的 `select([source.id])`。该操作只替换选中节点与清除边选择，不提交图变更，也不进入撤销栈或触发保存。

## 已验证事实

- `node-preview.test.ts` 覆盖图片输出优先、导入图片回退、视频输出以及非媒体节点无预览素材，共新增 3 项测试。
- 浏览器预览建立图片到视频的首帧引用后，视频属性面板显示引用卡片；点击卡片后，画布选中态和属性面板均切换到来源图片节点。
- `pnpm verify` 全量通过：TypeScript 类型检查、48 项测试（46 通过、2 跳过）、Renderer/Desktop 生产构建和 Electron Runtime smoke test 均成功。
