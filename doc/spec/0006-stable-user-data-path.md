# 桌面端用户数据路径兼容

## 背景

桌面端显示名称从原内部名称调整为 `ILMhegAgent` 后，Electron 默认将 `userData` 目录随应用名改为新路径，导致原项目、模型配置、加密凭据和素材不再被当前进程读取。原数据仍保存在旧目录中。

## 目标

应用的展示名称可以独立变更，但持久化数据目录必须保持稳定，已有用户数据无需复制即可继续使用。

## 行为

- Electron 的展示名称继续为 `ILMhegAgent`。
- 在任何数据库、凭据、素材或 Chromium 会话数据初始化之前，将 `userData` 显式设置为 `appData/il-mheg-canvas`。
- 数据目录标识 `il-mheg-canvas` 作为兼容性标识保留，不随产品展示名称变化。
- 不自动删除、覆盖或合并 `ILMhegAgent` 目录，避免损坏用户在异常版本运行期间可能产生的数据。

## 验收

- 应用初始化读取旧 `il-mheg-canvas` 目录中的数据库和素材。
- `ILMhegAgent` 仍作为应用、窗口和安装包的显示名称。
- TypeScript 类型检查、自动化测试、生产构建和运行时冒烟测试通过。
