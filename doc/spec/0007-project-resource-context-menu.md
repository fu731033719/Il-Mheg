# 项目本地资源快捷入口

## 目标

项目列表中的每个具体项目都支持右键打开上下文菜单，并可从菜单快速打开应用保存该项目资源的本地素材目录。

## 交互

- 展开侧栏与收起侧栏中的项目入口都响应右键操作，并阻止浏览器原生菜单。
- 菜单显示在指针附近，同时约束在当前窗口可视区域内。
- 菜单提供“打开本地资源目录”操作；该操作针对触发菜单的项目，而不是当前已选项目。
- 点击菜单外部、按 `Esc`、窗口失焦、窗口尺寸变化、滚动项目列表、切换项目或切换侧栏展开状态时关闭菜单。
- 菜单使用 `menu` / `menuitem` 语义；打开后聚焦首个操作，键盘用户可直接执行或关闭。
- 打开目录失败时沿用应用全局通知显示错误，不改变当前项目和画布状态。

## 桌面安全边界

- Renderer 只向主进程传递项目 ID，不传递任意文件系统路径。
- 主进程使用公共 UUID schema 校验 ID，并确认项目存在后才执行目录打开操作。
- 快捷入口打开稳定用户数据目录下的统一 `assets` 素材根目录；现有图片和视频仍保持原有分类及分片存储结构，不迁移、不复制文件。
- 浏览器预览模式保留同形 API，但不执行本地文件系统操作。

## 验收

- 任意项目（包括非当前项目）可通过右键菜单触发本地资源目录打开。
- 展开和收起侧栏下均可使用，菜单不会溢出窗口。
- 非法或不存在的项目 ID 不会触发目录打开。
- TypeScript 类型检查、自动化测试、生产构建和桌面运行时冒烟测试通过。
