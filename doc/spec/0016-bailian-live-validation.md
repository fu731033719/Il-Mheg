# 百炼真实生成验证与下载恢复

用户授权在有余额的北京百炼账号运行各模型。当前轮次自限 30 元：两个图像模型各一张，五个视频模型各 5 秒，按已核对原价预计 26 元。保留独立测试项目、提示词、运行记录和输出素材。

真实调用发现远程生成成功后的下载超时。恢复时只查询已有 taskId 并下载既有结果，禁止用重新生成代替视频下载重试。同步图片若缺少已持久化结果地址，仅在剩余预算内最多补测一次，并单独计入预计费用。凭据继续通过现有 CredentialVault/safeStorage 使用，禁止输出明文密钥。

在临时诊断脚本中比较 Node fetch 与桌面 Chromium 网络栈下载，验证结果后再决定针对性修复。仅恢复本轮失败任务，不更改历史项目；下载成功后复用 AssetStore 与数据库成功提交路径。真实输出验证文件格式、像素/时长并保留可查看的样本。

已复现：26.7 MB 的 Prime 视频下载速度约 116 KB/s，需要超过原来的 120 秒截止时间；Chromium 网络栈也慢。将单次媒体下载截止时间延长为 10 分钟，保留 HTTPS、公开地址、重定向及大小限制。已有失败视频用支持续传的下载恢复，不再生成。
