# 视频首尾帧连线锚点

## 目标

视频节点需要通过连线落点直接表达首帧与尾帧的时间顺序，避免两条输入边汇入同一侧而产生歧义。

## 行为

- `first_frame` 输入边连接到视频节点左侧。
- `last_frame` 输入边连接到视频节点右侧。
- 提示词、参考图和视频等其他输入继续连接到节点的通用左侧输入锚点。
- 视频节点作为上游节点时，输出边继续从右侧输出锚点出发。
- 该规则仅改变画布连线的展示锚点，不改变持久化图结构、输入 binding、首尾帧推断顺序或运行编译结果。

## 验收

- 已有图和新建图中的 `first_frame` 边均显示在视频节点左侧。
- 已有图和新建图中的 `last_frame` 边均显示在视频节点右侧。
- 其他 binding 的连线位置保持不变。
- 自动化测试覆盖 binding 到目标锚点的映射。
