# 画布右键创建节点

## 目标

- 空项目不再显示居中的开屏创建引导，画布保持可直接操作的空白状态。
- 用户在画布空白区域打开右键菜单后，可以直接创建现有的可执行节点类型：提示词、图片生成、视频生成。
- 通过右键菜单创建的节点使用右键位置对应的画布坐标，需正确适配画布缩放和平移。

## 交互约束

- 右键菜单沿用当前主题的弹出层视觉，并限制在画布可见范围内。
- 打开右键菜单时关闭连接创建菜单并清除当前选择；点击画布、在菜单外按下指针、按 `Esc` 或切换项目时关闭菜单。
- 选择菜单项后立即创建节点并关闭菜单；节点仍通过现有 Store 提交、撤销/重做和防抖保存链路持久化。
- 分组不作为右键创建项。分组必须继续由两个或更多已选节点生成，避免产生无内容分组。
- 顶部工具栏中的现有节点创建入口保持不变。

## 验证

- Store 测试覆盖显式画布坐标创建节点。
- TypeScript 类型检查、自动化测试与 Renderer 构建通过。
- 在空项目中确认不显示开屏引导，空白画布右键菜单可以分别创建三种节点。
