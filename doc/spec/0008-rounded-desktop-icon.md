# 桌面应用图标圆角与阴影

## 目标

参考 ChatGPT 桌面图标的处理方式，将现有白底方形应用图标调整为带安全边距的白色圆角卡片，并增加柔和外阴影，降低图标的方正感。

## 行为

- `build/icon.png` 保持 1024×1024 画布。
- 白色背景缩进为居中的圆角卡片，不再铺满整个画布。
- 圆角卡片外增加向下扩散的柔和阴影，并保留透明画布以容纳阴影。
- 黑色 Il Mheg LOGO 在卡片内等比缩小、居中，保证周围留白均衡。
- Renderer 侧边栏和 favicon 继续使用原透明 SVG，不受桌面图标样式调整影响。

## 验收

- 图标四角透明，白色卡片具有连续平滑的圆角。
- 卡片边缘外存在半透明阴影，阴影不会被画布裁切。
- LOGO 完整包含在卡片内，与圆角边缘保持清晰安全距离。
- Electron Builder 能从新 PNG 正常生成 macOS 多尺寸应用图标。
- 类型检查、自动化测试和生产构建通过。
