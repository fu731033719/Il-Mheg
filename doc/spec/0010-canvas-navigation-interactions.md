# 画布导航交互规格

## 目标

统一桌面鼠标与 Mac 触摸板上的画布导航方式，使平移和缩放无需额外按键。

## 交互

- 在画布空白区域按住鼠标左键拖动时平移画布。
- Mac 触摸板双指滚动时，按横向和纵向增量平移画布，无需按压触摸板。
- 鼠标滚轮滚动时，以指针位置为中心缩放画布。
- Mac 触摸板双指捏合时，以手势位置为中心缩放画布。
- 画布缩放继续受现有 `0.15` 至 `2.5` 的范围约束。
- Shift + 左键拖动继续提供框选；节点本身仍可用左键拖动。
- 现有中键/右键拖动画布、右键菜单、节点连接和小地图交互保持可用。

## 输入判定

浏览器把鼠标滚轮和触摸板双指滚动都表示为 `wheel` 事件，因此 Renderer 使用事件粒度、横向增量和连续手势窗口区分二者：

- `ctrlKey` 为真时视为 Chromium 在 macOS 上报告的触摸板捏合，交给 React Flow 的 pinch zoom 处理。
- 离散行/页滚动、传统滚轮增量或首个大幅整数纵向增量视为鼠标滚轮。
- 其余像素级连续滚动视为触摸板平移；同一短时连续输入沿用首次判定，避免惯性阶段改变行为。

## 验收

- 左键拖动画布空白处会改变 viewport 的 `x`、`y`。
- 触摸板双指上下、左右或斜向移动会对应平移 viewport，且不需要点击或按压。
- 鼠标滚轮会改变 viewport 的 `zoom`，缩放锚点下的画布坐标保持不变。
- 触摸板捏合会改变 viewport 的 `zoom`，普通双指移动不会缩放。
- 导航结束后的 viewport 继续保存到项目图状态。
