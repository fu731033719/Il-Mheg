# 属性面板节点引用导航

## 目标

- 图片或视频节点存在输入连线时，属性面板的“输入素材”列表展示每个来源节点的缩略预览。
- 用户点击引用项后，立即将对应的来源节点设为当前选中节点，并由属性面板展示该节点内容。

## 展示规则

- 图片来源优先显示节点最新输出图片；没有输出时回退到该节点导入的本地源图片。
- 视频来源存在输出素材时显示视频缩略预览。
- 提示词来源、没有可用素材的媒体来源或素材类型不匹配时，显示对应节点类型图标作为占位。
- 每项同时保留输入绑定名称和来源节点名称，长名称需截断，完整节点名称通过可访问标签和提示文本保留。

## 交互约束

- 整个引用项均可点击，并具有明确的按钮语义、悬停和键盘聚焦反馈。
- 点击只更新选中节点，不改变连线、图内容、撤销栈或保存状态。
- 来源节点不存在时不渲染失效引用项；图校验仍负责防止正常数据出现孤立连线。

## 验证

- 单元测试覆盖节点预览素材选择优先级和无素材回退。
- TypeScript 类型检查、自动化测试与生产构建通过。
- 浏览器预览确认引用缩略图可见，点击后属性面板切换到来源节点。
