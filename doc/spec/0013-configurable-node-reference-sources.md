# 可配置节点引用源

## 目标

将图片、视频节点的所有上游输入统一呈现为“引用源”，并允许用户在目标节点的属性面板中直接调整每个图片引用源的用途。已有的源图片、首帧、尾帧、参考图、视频与提示词 binding 继续作为持久化和编译边界，避免破坏现有画布数据与 Provider adapter。

## 交互

- 属性面板使用统一的“引用源”区域展示目标节点的全部入边；本地导入图片仍作为图片节点自身的素材配置，不伪装成节点引用。
- 每条引用源显示预览、来源节点名称和当前用途。
- 图片节点指向视频节点时，用途可在“首帧”“尾帧”“参考图”之间自由切换；其他节点组合只有一种合法用途，只读展示其语义。
- 点击引用源的主体仍导航到来源节点；操作用途选择器不得触发导航。
- 首帧和尾帧各最多一个。把引用源改为已被占用的首帧或尾帧时，原占用者与当前引用源交换用途；如果当前引用源原本是参考图，原占用者改为参考图。
- 参考图、源图片和源视频的索引在每次调整后按边的稳定顺序连续归一，界面不暴露内部的零基索引。
- 修改用途进入现有撤销/重做与自动保存流程；画布连线锚点随新用途立即更新。

## 领域约束

- 合法用途由来源和目标节点类型决定：提示词到图片/视频为提示词，图片到图片为源图片，图片到视频为首帧/尾帧/参考图，视频到视频为源视频。
- 领域层提供引用源用途查询与更新接口；Renderer 不直接修改 `CanvasEdge.binding`。
- 更新不存在的边、引用孤立节点或写入不兼容用途时必须失败，不产生部分修改。
- 现有新连线默认分配规则保持不变：图片到视频依次为首帧、尾帧、参考图。

## 验收

- 领域测试覆盖可选用途、普通用途切换、占用用途交换、参考图索引归一和非法调整。
- Store 测试覆盖属性调整写入撤销历史并更新图数据。
- Renderer 类型检查、全量测试、生产构建与运行时 smoke test 通过。
